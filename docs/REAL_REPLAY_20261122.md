## 距离完整论文实验仍缺什么

1. 将持续到达监测连接到真实调优控制器；负载切换期间的混合阶段测量必须失效，不能给 GP 写入错误上下文标签。
2. 为动态性能选择、校准并冻结与实际到达模式一致的目标与测量协议。当前 10/30 QPS 低速回放不是饱和性能寻优，不能直接沿用静态 OLTP TPS 数值。
3. 准备独立重复的数据快照恢复，冻结正式规模、参数空间、模型和预算。
4. 完成真正的同协议基线、消融和独立种子重复；最后再评价收益、适应耗时、代理误差/覆盖率与成本。

没有把本轮阶段识别当成调优适应完成，也没有把低速无失败当成执行安全性已被全面证明。完整动态对比实验尚未完成。
