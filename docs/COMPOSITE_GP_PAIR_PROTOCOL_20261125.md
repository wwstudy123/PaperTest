# 新GP接入综合目标闭环：同预算先导对照协议

本协议在新一轮付费执行前冻结，不使用旧记录训练新模型，不覆盖已有实测。本次比较是两种GP策略的闭环先导，不是AgenticDB/AgentTune等正式基线，也不是多种子显著性实验。

## 1. 显式接入与隔离

- `admtune.composite_static`新增 `--gp-policy legacy|repeat-aware`，默认legacy；不改旧入口默认行为。
- 新策略直接使用已验收的 `RepeatAwareGP`，每批新增有效观测更新，固定噪声进入训练协方差，预测仍区分潜在/观测标准差。
- `--initial-noise-repeats 3`显式启用预算内初始重复；不传仍为旧8槽位协议。
- 模型策略、重复计划及预算进入新协议指纹；账本绑定策略，禁止同一本账中途切换GP或重复计划。快照同时保存GP及重复证据来源。
- 仍用同次TPS/P95的6位小数规范标签及其对数，不把分数写成TPS。候选的硬校验、LCB/UCB、1%接受阈值、有限刷新及恢复规则不变。

## 2. 两臂及共同预算

固定顺序先Legacy、后RepeatAware，各自独立冷恢复、独立账本：

| 臂 | GP参数 | 输出编号 |
|---|---|---|
| Legacy | `--gp-policy legacy` | `composite-pair-legacy-001` |
| RepeatAware | `--gp-policy repeat-aware` | `composite-pair-repeat-001` |

两臂均指定 `--initial-noise-repeats 3`，每臂最多10次真实测量、1500秒活动预算、6次实际API尝试、24000 tokens（含未知失败预留）。两臂总上限20次测量、12次API/48000 tokens；允许提前停止，不补齐预算。API预留与实际tokens必须分开报告，不猜测人民币费用。

为末端独立复测、恢复及1次增量反思预留时间/调用和10000 tokens请求前预算。10号最终复测不再提前触发普通检查点反思，避免重复消费新增证据或侵占末端反思预留。

开始每臂前检查无其他压测，磁盘须能容纳冷恢复副本并至少留2 GiB余量。若不足则停止，不删除旧数据、不压缩替换未核验的目录。

## 3. 预先声明的初始重复

1. 第1次为共同初始配置基线。
2. 第2～4次仍测同一初始配置，标记 `noise_calibration`，真实占用测量、时间预算，不调用LLM。
3. 重复不晋升父配置，不把最高一次重复当作搜索收益；接受和筛选的基线锚点仍为第1次实测，不偷偷改成最好值或重定义历史标签。
4. 初始重复提供3个组内自由度，但只有一个配置的重复信息；不能据此假设其他配置同方差或模型已可靠校准。
5. 任一次初始校准无效则保存并停止，不自动补测或重开账本。
6. 之后启动真实LLM角色。仍保留每5号的固定审计；有效观测达到6条后拟合GP，筛选/拒绝新候选，必要时有限刷新。
7. 最后独立复测接受的父配置，并在保留预算内增量反思。最终复测不是搜索发现，不能回填成最优值。

四次初始配置测量是预先固定的校准开销，不是候选拒绝后的无意义重复。两臂规则完全相同，旧71次、旧综合闭环、两轮固定配置GP验收均不导入训练。

## 4. 环境及比较边界

专用MySQL 8.0.36、四表各200万行、完整五参数空间；32线程uniform只读、种子42、15秒预热+60秒正式测量、不限速。仅修改数据库参数，持久性和OS配额不变。角色模型及提示沿用已配置设置，不为任一臂人工指定推荐结果。

两臂独立测量、独立LLM响应，执行时间和生成候选可能不同；固定先后顺序也可能受时间变化影响。因此只能报告同预算、同协议的单次先导结果，不能单独归因GP、证明总体优势或替代多种子消融。

比较实测目标、TPS/P95、测量和角色开销、GP参与情况、区间误差、接受/恢复、反思及异常。只比较实测，不拼接文献曲线或旧实验数据，不因结果差而换顺序、加预算或挑最好点。

## 5. 运行与实现验证

两臂共用原有入口和显式付费授权，分别传相应策略：

```sh
python -m admtune.composite_static \
  --target configs/local/workset-v2-target.yaml \
  --benchmark configs/local/timed-readonly-100min.yaml \
  --knobs configs/local/concurrency-knobs.yaml \
  --output runs/composite-pair-repeat-001 \
  --restore-audit runs/composite-pair-repeat-restore-001/restore.json \
  --gp-policy repeat-aware --initial-noise-repeats 3 \
  --dedicated-instance --allow-paid-llm
```

Legacy臂替换策略和输出/恢复目录。每臂代码、初始快照、模型及源记录哈希保存。默认8槽位旧入口保持可用，不能将新预算与旧8槽位运行当作公平对照。

新增回归覆盖默认兼容、策略隔离、校准真实扣费且不晋升、无效校准停机、重复证据快照、最终复测及10号末端反思预留。单元测试均为明确夹具，不构成真实效果证明。
