## 系统调优删除范围

已删除系统参数搜索空间、配置类型与加载器、应用和恢复工具、控制项校验器、审计切换、启发式建议、模拟写入、经验摘要字段和报告分支。

`agenticdb` 与 ADMTune 都只支持数据库动作，不再提供 `--dbms-only` 开关。旧配置中的系统调优段和已移除审计选项会明确报错，不会被静默忽略。

保留的系统采集器只读取 CPU、内存、磁盘、压力和 I/O 诊断信息。数据库服务重启属于数据库执行生命周期，并不等于系统参数调优。

## 成本与执行规则

- 离线测试和模拟矩阵不调用模型接口、不连接数据库。
- 付费角色需要明确的接口、模型、`--allow-paid-llm` 及全局调用和令牌预算。
- 付费模式不隐式重试、不静默降级；失败且无法获得用量的请求保留预算预留。
- 最终复测占用试验预算，不能算作预算外免费操作。
- 启发式角色调用次数与真实接口调用次数分开记录。
- 实机预检读取未调参数中的连接数和缓冲区配置，用于联合内存筛查；该估计不是总内存占用的数学上界。

## 报告解释

合成 `suite.json` 和 `suite.csv` 仅是链路审计。未达到收益门限的运行保留空值，不剔除失败项后只统计成功项。

预测误差与覆盖率使用试验前预测，但只覆盖被选中的在线观测，仍有选择偏差。需要另设抽样审计集，才能评价更一般的校准能力。覆盖率必须与区间宽度共同报告。

运行清单保存种子、参数全集、环境标识、依赖、Git 提交号、未提交修改标记和源码哈希。实机另存基准状态与测量协议。独立复测值不回填为搜索最优值。总命令耗时包含预检和最终恢复，调优账本另行记录活动时间。

已完成专用容器部署、预检、无模型手工试验、定向重启和小预算真实模型静态联调。记录见 [真实静态联调](SERVER_SMOKE_20261122.md)。未另跑启发式静态搜索，不能将手工试验描述为该步骤。

两组真实动态回放及数据归档也已完成，见 [真实动态回放记录](REAL_REPLAY_20261122.md)。这不等于完整动态调优实验。

固定负载和短时扰动两组真实负对照也已完成并双份留档，见 [监测负对照记录](MONITOR_CONTROLS_20261123.md)，没有额外阶段确认。

阶段时长不兼容已增加预算预检、阶段准入和观测失效保护，并完成实机验收，见 [阶段保护验收](PHASE_GUARD_20261123.md)。没有缩短原来的 15+60 秒观测时长，也没有宣称正式时长校准已经完成。

1. 实现与外生负载同协议的动态性能执行器及独立调优线程，接入已验证的预算与栅栏组件；不能把静态 Sysbench 注入单 SQL 回放。
2. 校准测量稳定性、阶段阈值与接受规则，准备数据快照还原。
3. 冻结正式规模、参数空间、模型、预算及基线和消融协议。
4. 在相同协议下开展独立重复，正式对比前不扩大联调性能结论。

同一数据库实例一次只运行一个调优进程。当前没有分布式实例锁，也不自动恢复数据快照。

## 容器部署适配

新增 `--local` 本地执行，不依赖 SSH 或 root 容器中的 sudo。MySQL 支持由明确的配置、socket、PID 和二进制路径管理独立进程；重启仍需显式授权。不恢复操作系统调优能力。

模型接口新增可选 `OPENAI_ENABLE_THINKING`，只有明确配置时才发送。模型参数需先通过一次小预算联调，再开展完整搜索。
