# 零LLM重复测量与GP区间校准协议

本轮只验证测量波动和区间，不做新的候选搜索，不改在线GP，不调用LLM。保留前两轮综合目标闭环的全部数据。

## 固定配置与测量

- 复用已实测通过的 `admtune.static_diagnostic --concurrency-probe`，以新编号 `uncertainty-repeat-001` 独立运行。
- 三个固定配置为Default、BufferOnly、Concurrency8：均为io_capacity=200、max=2000、排序缓冲256 KiB；Default缓冲池1 GiB/并发0，其余缓冲池4 GiB、并发分别为0/8。不再人工试选别的取值。
- 顺序固定为D/B/C、B/C/D、C/D/B，共9次，各配置在每个区组和位置各出现一次；不是随机种子重复。
- 同一MySQL 8.0.36专用实例，四表各200万行，32线程、uniform、种子42、15秒预热+60秒正式测量，不限请求速率。
- 开始前独立冷恢复，每次恢复共同初始配置及完整并发上下文，但不每次冷清空缓存；不修改OS参数或持久性。
- 最多9次测量、0次API、0 tokens；不自动补测失败点。复用执行器1500秒提交截止，预计约12～15分钟，完成后恢复及审计。不声称严格抢占式墙钟上限。

## 预先固定的离线时间切分

1. 前两个区组（1～6号，每配置2次）仅作为校准数据；第三个区组（7～9号，每配置1次）留作检验。
2. 目标为同次测量TPS/P95(ms)，训练标签仍按6位小数规范化后取自然对数；不混入纯TPS标签。
3. 比较两种基础GP：第二轮综合闭环最后保存的7观测GP（冻结超参数与训练集）；以及只用本轮前6次观测、同核同编码、固定种子42重新优化的GP。
4. 从前6次规范对数标签计算按完整配置分组的组内残差平方和，除以自由度`6-3=3`，得到合并组内方差`s²`。
5. 分别对两个基础GP比较原观测标准差与噪声地板版本。后者仅令预测观测方差为`latent_var + max(fitted_noise_var, s²)`，均值、核和后验拟合不变；不是声称已实现带噪声地板的GP重训练。
6. 所有拟合、方差估计、模型选择设置均不得读取7～9号目标。第三个区组不用于调阈值、挑版本或重新拟合；即使结果不好也全部报告。
7. 本轮执行器不在线预测；完成后严格按时间切分离线重建，不能写成“预测在真实执行前已提交”。前6次拟合误差也不冒充检验误差。

## 核验与边界

- 保存原生Sysbench日志、实际TPS/P95、CPU/节流边界、配置与恢复证据、冻结父模型、全部训练来源、三检验点预测/区间及哈希。
- 报告各配置重复值与离散程度、检验点误差和±2倍观测标准差覆盖；区分潜在函数不确定性与观测噪声。
- 合并方差只有3个自由度，独立检验只有3点，不能据此证明总体95%覆盖或泛化可靠。
- 同配置跨时间差异不直接当作某参数因果作用；容器CPU包含压测客户端，不能只归因MySQL。
- 不用校准后的区间回填旧预测，不覆盖原始漏覆盖事实，不在本轮自动修改在线模型或启动付费搜索。
