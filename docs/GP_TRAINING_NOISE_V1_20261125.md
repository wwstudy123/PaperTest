# 训练噪声与更新调度新版本：实现完成，独立实测待验收

本次仅完成代码和离线回归，不新增数据库测量、不调用LLM，也不把前一轮三个检验点拿来挑选新参数。旧[重复测量与区间漏覆盖结果](UNCERTAINTY_REPEAT_RESULTS_20261125.md)保持不变。

## 1. 为什么不是再加宽误差条

上一轮地板只改变观测预测区间，不影响训练矩阵及潜在函数不确定性，而在线LCB/UCB使用潜在函数标准差。因此，本次在GP训练中显式加入固定观测方差，并提供独立的重复证据更新器。

新训练矩阵：

```text
K_train = K_kernel + (sigma_residual_norm² + sigma_fixed_log² / target_scale² + jitter) I
```

`sigma_fixed_log`使用原始对数目标单位。残余噪声仍由边际似然优化，两者按方差相加；**不是把残余噪声参数直接截成地板，也不是只在预测输出上改数字**。总观测标准差同时用于观测预测，潜在后验也通过训练矩阵受到影响。

`GaussianProcess.fit(..., fixed_noise_log_std=0)`默认固定项为0；旧在线控制器不传新参数，因此继续使用原行为。旧快照不要求新字段；启用固定项的新快照记录参数化、固定噪声和总噪声，重载时核验。

## 2. 重复证据更新器

独立模块：`admtune/repeat_aware_gp.py`，策略名 `repeat_aware_gp_v1`。

- 只接受同环境、同综合目标的完整有效观测，目标为同次TPS/P95的规范值。
- 按环境、目标、阶段、完整配置和上下文共同分组，避免把不同负载阶段当成配置重复。
- 合并组内残差平方和，除以组内自由度。至少3个重复自由度时，才把估计标准差作为固定训练噪声项；这只是预先固定的工程门槛，不是统计可靠性证明。
- 自由度不足时仍记录估计，但固定项为0。即使只有第一对重复，新观测到来后也重优化，不再等待第10个模型版本。
- 至少6条有效观测启动，每批新增有效历史都执行原来有界的两起点、最多60步边际似然优化；没有新增历史时不重复拟合。
- 历史必须追加且不可改写，重复编号、目标/环境混合、失败标签和非有限值拒绝使用。
- 训练失败不覆盖上一成功模型；快照记录证据指纹、噪声审计和参数，重载后再检查实际历史与训练数组对应。
- 不会自动申请真实重复测量，更不会通过重复填充试验预算。

残余噪声超参数位于标准化目标空间，固定项位于原始对数目标空间；新快照明确区分两者。固定项可能为0，不能把“自由度足够”写成测得了正噪声。

## 3. 实测验收入口已准备，但默认关闭

`admtune.static_diagnostic`新增 `--repeat-aware-audit`，必须同时指定 `--concurrency-probe`。不传新标志时，不启动新审计路径。

该入口不是完整ADMTune搜索，而是固定三个配置、九次测量的零LLM比较：

1. 使用同一批过去观测，分别拟合原“每10模型版本优化”策略和新“每批新增观测重优化+训练噪声”策略。
2. 第7、8、9号测量之前，先保存各自的模型快照、训练编号、预测均值、潜在/观测标准差及提交时间。
3. 当前观测完成后才可以进入下一次预测的训练集。例如7号可用于预测8号，但不能用于预测7号。
4. 配置顺序固定，不由任何模型选择；因此没有代理筛选改变负载或比较对象的混杂。

新协议见[独立顺序预测验收协议](GP_NOISE_VALIDATION_PROTOCOL_20261125.md)。本次尚未执行该验收，不存在可以报告的新版本真实性能或覆盖率。

## 4. 回归验证

新增22项测试，本地合计252项通过，主要验证：

- 固定噪声确实进入训练矩阵并改变潜在后验，不只改变观测误差条。
- 原始对数单位在目标标准化尺度变化后仍正确。
- 默认零固定项与旧快照预测兼容。
- 新快照重载一致，未知参数化和噪声审计篡改被拒绝。
- 环境/目标/阶段/上下文分组、自由度门槛、追加历史和训练失败保护。
- 新观测触发重优化，旧历史不反复拟合。
- 预测文件先封存，不覆盖既有提交，不混入当前或未来标签。

所有新增模型测试使用明确的合成夹具；旧实测快照只用于向后兼容检查，不作为新版本效果证明。没有覆盖旧实验数据或重写旧预测。

## 5. 尚未证明什么

新代码没有解决所有跨时间变化、异方差或模型失配。合并噪声不能保证不同配置有相同波动，也不能保证置信区间达到某个总体覆盖率；重新优化不保证搜索收益。

固定项也是从训练数据估计的工程约束，不是已知真实噪声；它可能改变预测均值、排序与区间，必须用新的顺序检验数据评估，不能由“加入协方差”推断效果必然更好。

当前付费综合闭环仍使用原策略，未自动切换。下一步只运行新协议的独立零LLM验收；先看真实顺序预测和恢复证据，再决定是否接入新的小预算付费闭环，而非直接扩大到100分钟。
